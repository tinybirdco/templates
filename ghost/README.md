## Ghost(Pro)

If you’re on Ghost(Pro), web analytics are available automatically by default, no setup required — and can be turned off anytime from **Settings → Analytics** in Ghost Admin.

## Self-hosting

To use native web analytics in a self-hosted Ghost environment, your site must be running `Ghost 6.0` or higher using the Docker Preview installation method, with an active Tinybird account configured.

[Learn more](https://ghost.org/integrations/tinybird/)
